# Vanilla Stable Diffusion (PyTorch Engine) 

Минималистичная, легковесная и полностью независимая реализация инференса **Stable Diffusion v1.5** на **PyTorch**.

Проект создан как альтернатива тяжеловесным библиотекам (вроде HuggingFace `diffusers` или оригинальному коду на `PyTorch Lightning`). Архитектура сети (U-Net, VAE, CLIP) и логика сэмплера (DDPM) воссозданы вручную в виде чистых `torch.nn.Module` без использования сторонних абстракций, конфигураторов или внешних фреймворков.

## Ключевые особенности
* **Dependency-Free Architecture:** Вся архитектура реализована исключительно на `torch`. Отсутствует зависимость от `diffusers`, `einops` или `OmegaConf`.
* **Полный стек Stable Diffusion:**
  * **U-Net:** Кастомная реализация с ResNet-блоками и механизмами Self/Cross-Attention.
  * **VAE:** Вариационный автоэнкодер для кодирования и декодирования латентного пространства.
  * **CLIP Text Encoder:** Интеграция текстового энкодера и токенизатора для работы с промптами.
* **Кастомный DDPM Sampler:** Полностью самописная логика марковских цепей (вычисление дисперсии, добавление шума, шаги денойзинга).
* **Скрипт маппинга весов:** Написан собственный загрузчик, который конвертирует и переносит официальные веса (CompVis) в структуру данной реализации.
* **Мультиязычность:** Встроенная поддержка промптов на русском языке (с автопереводом под капотом).
* **Режимы:** Поддержка Text-to-Image и Image-to-Image.

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ТВОЙ_НИК/vanilla-stable-diffusion.git
cd vanilla-stable-diffusion
```

### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение.
```bash
pip install -r requirements.txt
```

### 3. Загрузка весов (Checkpoints)
Используются официальные веса Stable Diffusion v1.5. 
Создайте директорию `data` в корне проекта и скачайте туда следующие файлы:

1. [v1-5-pruned-emaonly.ckpt](https://huggingface.co/runwayml/stable-diffusion-v1-5/resolve/main/v1-5-pruned-emaonly.ckpt) — основные веса модели.
2. [vocab.json](https://huggingface.co/openai/clip-vit-large-patch14/resolve/main/vocab.json) — словарь токенизатора CLIP.
3. [merges.txt](https://huggingface.co/openai/clip-vit-large-patch14/resolve/main/merges.txt) — правила токенизации CLIP.

### 4. Использование (CLI)
Проект управляется через удобный интерфейс командной строки (main.py).
Text-to-Image (Генерация по тексту)
```bash
python src/main.py --prompt "Город будущего, неоновые огни, детализация" --steps 50 --seed 42
```
Результат по умолчанию сохраняется как output.png.
Image-to-Image (Генерация на основе картинки)
```bash
python src/main.py --prompt "Акварель, размытые пастельные тона, мягкие переходы" --image "./source.jpg" --strength 0.75 --steps 50
```
Дополнительные параметры:
- `--prompt` — Текст для генерации.
- `--negative_prompt` — Негативный промпт (что убрать с изображения).
- `--image` — Путь к исходному изображению для режима img2img.
- `--strength` — Сила зашумления для img2img (0.0 - 1.0).
- `--steps` — Количество шагов сэмплера DDPM.
- `--seed` — Зерно генерации для фиксации результата.
- `--output` — Путь и имя файла для сохранения.

Код разбит на логические модули для прозрачности процессов:
- `diffusion.py` — Описывает ядро (U-Net), отвечающее за предсказание шума на каждом шаге.
- `ddpm.py` — Планировщик Denoising Diffusion Probabilistic Models.
- `vae.py` — Компрессия в латентное пространство (кодирование/декодирование).
- `clip.py` — Трансформер для работы с текстовыми эмбеддингами.
- `attentions.py` — Механизмы пространственного и кросс-внимания.
- `load_model.py` — Мост-конвертер ключей из оригинального .ckpt файла в слои кастомной реализации.
